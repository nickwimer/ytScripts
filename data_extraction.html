data_extraction.extract_averages module¶

usage: extract_averages [-h] [--datapath DATAPATH] [--outpath OUTPATH]
                        [--pname PNAME [PNAME ...]] [--SI] [--verbose]
                        [--no_mpi] [--nprocs NPROCS] [--nskip NSKIP]
                        [--ifile IFILE] [--fields FIELDS [FIELDS ...]]
                        [--name NAME] [--normal NORMAL] [--location LOCATION]
                        [--rm_eb]

Named Arguments¶

--datapath

Path to the folder holding the data files. (required)

--outpath

Path to the output directory.

--pname

Plotfile names or quoted patterns inside –datapath, e.g. plt01000 or “pltReact*”. Any name works. Without it, every plotfile named plt<digits> is used.

--SI

Flag to set the units to SI (default is cgs).

Default: False

--verbose

Flag to turn on various statements.

Default: False

--no_mpi

Never start MPI, even when launched with mpirun or srun. MPI is only used when launched that way.

Default: False

--nprocs

Number of processors to devote to each file when operating inparallel mode

Default: 1

--nskip

Skip every “nskip” entries in “pname” list.

--ifile

Path to the input file for configuring plots.

--fields

Names of the data fields to extract. (required)

--name

Name of the output data file (.pkl).

Default: 'average_data'

--normal

Option to average over a 2D slice with this normal (defaults to domain average): x, y or z, a pair of different axes such as xz (normal (1, 0, 1)), or a signed pair such as x-z (normal (1, 0, -1)).

--location

Physical location to perform the 2D slice (if normal is defined). For a diagonal normal, the distance from the origin along the unit normal.

--rm_eb

Flag to explicitly remove all data in EB regions.

Default: False

Extracts domain averaged quantities and saves for plotting.

data_extraction.extract_isosurfaces.retrieve_ghost_zones(cube, n_zones, ds_left_edge, ds_right_edge, do_gradient)[source]¶

Return a grid grown by ghost cells, and its child mask padded to match.

The ghost cells come from a covering grid at the grid’s own level, so the grown grid keeps the original cell size and lines up with the original cells.

The padded mask is False in the ghost cells. marching_cubes only processes a cell when the mask is True at the cell’s upper corner, so the ghost layer below a grid fills the gap to its lower neighbor (closing the crack between them) and the layer above it is never used. Each gap is therefore filled once, by the grid above it.

data_extraction.extract_isosurfaces.sample_at_vertices(volume, verts, spacing)[source]¶

Interpolate a cell-centered field to isosurface vertices.

verts are the positions marching_cubes returned for an array the same shape as volume with the given spacing (before any offset), so dividing by the spacing gives fractional cell indices. Trilinear interpolation matches the linear interpolation marching cubes uses along each cell edge.

data_extraction.extract_lines.lines_to_dataframe(lines, normal)[source]¶

Combine the line from each time into one table.

lines maps each time to (positions, values, ...). With AMR the cells along the line can change from one time to the next, so each line keeps its own positions. The table is indexed by every position seen at any time, sorted, with one column per time and NaN where that time has no cell at that position.

data_extraction.extract_lines.take_line(ds, normal, coords, data_source=None)[source]¶

Return the positions along a line and the cells it passes through.

Along an axis the positions are that coordinate of the cells. Along a diagonal they are the distance from the origin along the unit direction of the middle of each cell’s stretch of the line, so normal . r for points on the line.

data_extraction.extract_slices.cut_plane(ds, ds_attributes, normal, across, up_vec, distance)[source]¶

Cut the plane normal . r = distance and make a fixed resolution image of it.

The image covers the part of the plane inside the domain, with one pixel per finest cell, across to the right and up_vec up. Returns the cutting plane, the image and what places it: the unit normal, across and up vectors, the image center and its bounds (across_min, across_max, up_min, up_max) as positions along across and up, in code_length. Those positions are the same for every slice with this normal, so the slices line up when plotted.
