usage: slice_plot [-h] [--datapath DATAPATH] [--outpath OUTPATH]
                  [--pname PNAME [PNAME ...]] [--field FIELD] [--SI]
                  [--verbose] [--no_mpi] [--nprocs NPROCS] [--nskip NSKIP]
                  [--ifile IFILE] [--normal NORMAL]
                  [--grid_offset GRID_OFFSET] [--up {x,y,z}] [--cmap CMAP]
                  [--dpi DPI] [--pbox PBOX [PBOX ...]]
                  [--fbounds FBOUNDS [FBOUNDS ...]]
                  [--center CENTER [CENTER ...]] [--plot_log]

Named Arguments¶

--datapath

Path to the folder holding the data files. (required)

--outpath

Path to the output directory.

--pname

Plotfile names or quoted patterns inside –datapath, e.g. plt01000 or “pltReact*”. Any name works. Without it, every plotfile named plt<digits> is used.

--field

Name of the field for visualization.

--SI

Flag to set the units to SI (default is cgs).

Default: False

--verbose

Flag to turn on various statements.

Default: False

--no_mpi

Never start MPI, even when launched with mpirun or srun. MPI is only used when launched that way.

Default: False

--nprocs

Number of processors to devote to each file when operating inparallel mode

Default: 1

--nskip

Skip every “nskip” entries in “pname” list.

--ifile

Path to the input file for configuring plots.

--normal

Normal direction for the slice: x, y or z, a pair of different axes such as xz (normal (1, 0, 1)), or a signed pair such as x-z (normal (1, 0, -1)).

Default: z

--grid_offset

Amount to offset center to avoid grid alignment vis issues.

Default: 0.0

--up

Possible choices: x, y, z

Axis pointing up in the image, one of the two axes in the slice (default: z for normal x and y, y for normal z). For a diagonal normal the default is the axis not in it, e.g. y for xz, and an axis not in the plane is tilted into it.

--cmap

Colormap for the 2D plot.

Default: 'dusk'

--dpi

dpi of the output image (default = 300).

Default: 300

--pbox

Bounding box of the plot specified by the two corners (x0 y0 x1 y1), as positions across and up the image.

--fbounds

Bounds for the colorbar.

--center

Coordinate list for center of slice plot (x, y, z).

--plot_log

Plot in log values.

Default: False

--grids

Options to specify annotate grids (alpha, min_level, max_level, linewidth).

--cells

Options to specify annotate cells (linewidth, alpha, color).

--buff

Buffer for the SlicePlot image for plotting.

--contour

Name of contour field, value, and color to plot on top of slice.

--clw

Linewidth for each of the contour lines.

--pickle

Flag to store image as pickle for later manipulation.

Default: False

--grid_info

Add text box with grid information (xloc, yloc, min_lev, max_lev).

--rm_eb

Float value to plot non-fluid using binary cmap [0, 1].

--gradient

Possible choices: x, y, z, magnitude

Choice to visualize the gradient of the input field.

--no_time

Flag to remove the timestamp.

Default: False

--no_units

Flag to remove all units from plots.

Default: False

--add_udf

Name of user defined functions file (located in udfs/).

--use_tex

Render plot text with LaTeX (off by default). Needs a working TeX install and is slower.

Default: False

2D slice down the middle of the domain.

quick_vis.slice_plot.configure_tex(use_tex)[source]¶

Render plot text with LaTeX, only when asked for and LaTeX is installed.

LaTeX rendering is opt-in: it is slower, and a broken TeX install can make matplotlib wait forever on its luatex helper. Returns whether it is on.

quick_vis.slice_plot.contour_lines(image, level, extent)[source]¶

Return the contour lines of an image in plot coordinates.

image is indexed [row, column] with row 0 at the bottom, and extent is (left, right, bottom, top) of the whole image, as matplotlib’s imshow uses. Each line is an (N, 2) array of horizontal and vertical positions, measured from the pixel centers.

quick_vis.slice_plot.image_axes(normal, up=None)[source]¶

Return the axes drawn across and up the slice image, and whether yt swaps them.

yt draws (y, z) for normal x, (z, x) for normal y and (x, y) for normal z, and its swap_axes() exchanges the two. up names the axis to draw up the image. Without it, this script keeps yt’s choice, except that it swaps the axes for normal y so that z points up there too.
