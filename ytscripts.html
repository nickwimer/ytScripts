ytscripts.utilities.canonical_normal(name)[source]¶

Return a –normal value in its standard form: x+z and zx become xz.

An unsigned pair names the same normal in either order, so its axes are sorted. A signed pair keeps its order, since z-x points the other way from x-z.

ytscripts.utilities.create_index_dict(names)[source]¶

Number each plotfile by its place among those named the same way.

Plotfiles that share a prefix and end in a number (plt00100, plt00200, …) are numbered 0, 1, 2, … in order of that number, so images made from them get consecutive frame numbers whichever of them are plotted. Names with no number at the end are numbered among themselves.

ytscripts.utilities.default_up(name)[source]¶

Return the axis drawn up a slice image by default.

z for normal x and y, y for normal z, and the axis left out of a pair, so y for xz and x-z.

ytscripts.utilities.enable_parallelism(no_mpi=False)[source]¶

Share yt’s work over MPI if this run was launched as several processes.

A plain single-process run never starts MPI. Returns True if yt runs in parallel.

ytscripts.utilities.find_plotfiles(datapath, pname=None, nskip=None)[source]¶

Find the plotfiles to load and number them for output names.

Without pname, every plotfile named plt<digits> in datapath is used, so other plotfiles a run writes alongside (such as pltU00100 or plt00100.old.1234) are left out. With pname, every plotfile matching those names or patterns is used, whatever it is called. nskip keeps every (nskip + 1)th file.

Returns the paths to load, in order, and a dict numbering every plotfile in datapath (see create_index_dict).

ytscripts.utilities.get_mpi_comm(no_mpi=False)[source]¶

Return the MPI communicator if this run was launched as several processes.

Returns None for a plain single-process run, without importing mpi4py, so MPI is never started and mpi4py need not be installed. Also returns None with no_mpi, where every process does all the work.

ytscripts.utilities.load_dataseries(datapath, pname=None, units_override=None, nprocs=1, nskip=None)[source]¶

Load a series of datasets from files in a given directory.

Parameters: - datapath (str): The path to the directory containing the dataset files. - pname (list, optional): Plotfile names or glob patterns inside datapath. When left out, every plotfile named plt<digits> is loaded. See find_plotfiles. - units_override (dict, optional): A dictionary specifying unit overrides for the loaded datasets. Default is None. - nprocs (int, optional): The number of processes to use for parallel loading. - nskip (int, optional): The number of files to skip between loaded datasets.

Returns: - ts (yt.DatasetSeries): A series of loaded datasets. - index_dict (dict): Maps each plotfile name to its frame number among the plotfiles named the same way.

ytscripts.utilities.plane_box_points(left_edge, right_edge, normal, point)[source]¶

Return the corners of the polygon where a plane cuts a box.

The plane holds point and has the unit normal. Raises ValueError if it misses the box.

ytscripts.utilities.plane_center(left_edge, right_edge, normal, distance)[source]¶

Return the point of the plane normal . r = distance nearest the domain center.

Raises ValueError unless the plane cuts through the domain. A plane at either end of the domain’s span only touches an edge or a corner, which leaves no area to draw, so it is refused too.

ytscripts.utilities.plane_window(left_edge, right_edge, normal, center, across, up)[source]¶

Return the part of a slice plane inside the domain, around its center.

The plane goes through center with the unit normal. Returns ((across_min, across_max), (up_min, up_max)), as offsets from center along the unit vectors across and up.

ytscripts.utilities.plotfile_sort_key(name)[source]¶

Sort plotfiles by prefix, then by the number at the end of the name.

This puts plt99999 before plt100000, which sorting by name alone does not.

ytscripts.utilities.slice_basis(name, up=None)[source]¶

Return the unit normal and the unit vectors across and up a slice image.

up names the axis to draw up the image (default from default_up()). An axis that is not in the plane is tilted into it, so for normal xz, up x points along (x - z)/sqrt(2). Across is up x normal, as in yt’s off-axis slices, so across, up and the normal form a right-handed set.

ytscripts.utilities.split_plotfile_name(name)[source]¶

Split a plotfile name into its prefix and the number at its end.

“pltReact01264” gives (“pltReact”, 1264); a name with no number at the end gives (name, None).
